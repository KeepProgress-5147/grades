🎓 111～115學年度大學分發入學最低錄取分數專案記錄

完整收錄 5 年（111～115 學年度）考分會分發入學錄取標準數據清洗、加權拆解、單科平均計算、醫療衛生五大群組排名分析、互動式儀表板與 GitHub 發布準備。

📌 一、專案背景與目標

本專案旨在將考分會公佈之 111 至 115 學年度（連續 5 年）「大學分發入學 各系組最低錄取標準及錄取人數一覽表」 PDF 原始文件，透過 Python 進行全自動化資料提取、字串清洗、欄位拆解、加權計算與跨年度彙整，並進一步針對 醫學、護理、聽語、視光、醫檢 五大醫療衛生核心學群（共 68 個系組）進行組內歷年排名統計、分數消長分析、互動式儀表板開發與 GitHub Pages 線上展示。

💬 二、討論過程與需求演進

1. 初始需求確認（115 學年度）

  • 核心欄位保留： 僅保留 校名、系組名、採計及加權、錄取人數(含外加)、普通生錄取分數。
  • 拆分採計及加權：
    • 科目：提取大考科目名稱（如國、英、數A、數甲、物、化等），並以頓號（、）分隔。
    • 加權：將各科權重係數加總（例如 1.50 + 1.25 + 1.25 + 1.00 = 5.0）。
  • 計算平均分數： 新增 平均分數 欄位（公式：普通生錄取分數 ÷ 加權總和，四捨五入至小數點後第 2 位）。
  • 缺額處理： 普通生錄取分數為 -----（無錄取標準／缺額）之系組直接留空白。

2. 多年度批次擴展與跨年度彙整

  • 陸續納入 111、112、113、114 學年度之原始 PDF 資料。
  • 比照 115 標準格式，產出各學年度獨立之 Excel 資料檔。
  • 抽取 111～115 連續 5 年之 校名、系組名 與 平均分數，自動對齊並合併為跨年度彙整總表（共 2,576 筆）。

3. 111 學年度資料深度除錯與修復

🔍 111 年度異常原因： 111 年 PDF 因字型間距（Kerning）特殊，傳統抽取會誤在數字與字串間產生空格（如 1 9、1 95.00、數Ax1.0 0）。
🛠️ 修復策略： 改用 pdfplumber 精確字形邊界解析引擎重新解析，徹底消除空格誤差，1,900 筆資料全數 100% 精準校正！

4. 醫療衛生五大群組深度分析、資料庫更新與 GitHub 發布準備

  • 68 筆核心醫療系組資料庫： 包含醫學（18系組）、護理（28系組）、聽語（5系組）、視光（4系組）、醫檢（13系組）。
  • 五大核心群組排名與 Excel 原生折線圖： 建立 大學部111-115成績_含折線圖.xlsx，涵蓋 68 筆醫療衛生系組，包含 5 年分數、組內排名（#1~#N）、五年分數增減值，並內建 Excel 原生圖表。
  • 互動式網頁儀表板： 建立 index.html（大學部111-115成績_互動圖表.html），採用 Apache ECharts 5 打造 90%+ 寬幅高對比儀表板，支援前 5 名聚焦、公立大學篩選、即時搜尋與排序。
  • GitHub Pages 發布支援： 配置標準 index.html、README.md 與 .gitignore，支援一鍵推播上線。

🚀 六、GitHub 上傳與 GitHub Pages 發布步驟

  1. 建立 GitHub Repository： 登入 GitHub 建立一個新的 Public 倉庫（例如命名為 university-scores-dashboard）。
  2. 上傳專案檔案： 直接將專案資料夾下的所有檔案拖曳至網頁上傳並 Commit。
  3. 啟用 GitHub Pages： 進入倉庫的 Settings ➔ Pages，在 Build and deployment 選擇 Deploy from a branch（Branch 選 main，資料夾選 / (root)）後點擊 Save。
  4. 即刻線上預覽： 等候約 1 分鐘即可透過 GitHub 專屬網址線上即時瀏覽互動式折線圖儀表板！
